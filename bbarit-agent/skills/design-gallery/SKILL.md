# Design Gallery — curated design skill library

95 design skills vendored from [MengTo/Skills](https://github.com/MengTo/Skills)
(MIT, commit 25f872a — see LICENSE in this folder). Each entry below is a full
skill with detailed instructions.

## How to use

1. Pick the closest entry from the index (match the user's requested style/effect).
2. Read `library/<path>/SKILL.md` (path is relative to this file) with the read tool.
3. Follow that skill's instructions; combine 2-3 skills freely (e.g. a layout style
   + an animation system + a background effect).
4. If the skill folder has extra reference files, read those too.

Rules of thumb: `web-design/*` are opinionated visual systems for landing/marketing
pages; `ui/*` set overall taste/quality bars; `media/*` fetch real image assets;
`codex/*` are workflow utilities (screenshots, deploy, profiling).
